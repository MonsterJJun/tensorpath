# Trust and performance boundaries

The recorder is imported by the user's trusted training process. The analyzer never imports torch and cannot execute model code, open arbitrary paths, run a command, or deserialize pickle/checkpoints. MCP uses local stdio and fixed directories specified at launch. Static discovery parses bounded Python source only inside an approved project; it returns candidate names/paths, not source bodies. HTML export writes a fresh file only inside the configured report directory; it does not accept a caller-supplied output path or open a browser. These directories must be private and stable (no adversarial concurrent filesystem changes). File IDs are restricted, direct symlinks are rejected, POSIX O_NOFOLLOW is used when available, regular files are required and parsing is size-limited. Trace publication refuses overwrites. This is not a multi-tenant sandbox: use a private directory, not one writable by untrusted users, and avoid hardlinks/reparse points/unreviewed JSON. Windows race-hardening is not equivalent to POSIX. A malicious trace can forge evidence or insert instructions in strings; treat all content as data, never commands. Do not use secrets in names or labels. Module classes, parameter names, architecture and gradient statistics may be confidential. No tensor values are intentionally serialized.

The recorder performs no implicit forward/backward, optimizer step, device move of parameters, or mode change. Explicit gradient probes perform extra autograd evaluations and bounded CPU copies; existing custom hooks and stochastic operations can affect behavior. Do not use on every training step without measuring overhead. Model code itself may be unsafe; only run code you trust. No guarantees for concurrency, torch.compile, distributed/sharded execution, exception recovery, or accelerator kernels. Six analysis tools and static discovery are read-only; HTML export is a write tool. MCP annotations are hints, not permission controls. Setup is explicit, preview-first and backup-first; stop Hermes and other config editors before applying. Restrict agent access to approved tools, and require user consent for code changes or runs. Report missing or truncated evidence honestly.
